What Is an M3U Playlist?

Learn what an M3U playlist is, how IPTV players use M3U links and why playlist information should be kept private.

M3U is a plain-text playlist format that can contain references to media streams and related information.

How M3U Works

An M3U file or URL can list stream locations in a structure that a compatible player understands. The player reads the references and presents them as available content.

Using an M3U Playlist

A player may ask you to enter a playlist URL or import an M3U file. Use only the playlist information supplied by a service you are authorized to use.

Keep Playlist URLs Private

Playlist URLs can contain access information. Do not post them publicly or share them with people you do not trust.
